# CS Curriculum Knowledge Pack

An OKF v0.2 example bundle: a small, fictional computer-science curriculum. The
course structure is illustrative demo content; factual claims about computer
science are cited to their sources in each concept.

## Courses

* [CS 101: Introduction to Programming](/courses/cs101.md) - Entry-level programming course in Python; no prerequisites.
* [CS 201: Data Structures & Algorithms](/courses/cs201.md) - Follow-on course covering data structures, recursion, and algorithm analysis.

## Topics

* [Recursion](/topics/recursion.md) - Functions that call themselves; the heart of divide-and-conquer.
* [Big-O Notation](/topics/big-o.md) - The standard vocabulary for describing how an algorithm's cost grows.
* [Sorting Algorithms](/topics/sorting.md) - Quicksort and merge sort as case studies in analysis.

## People

* [Grace Hopper](/instructors/grace-hopper.md) - Programming pioneer and naval officer; built the first compiler.

## Resources

* [Structure and Interpretation of Computer Programs](/resources/sicp.md) - The classic freely available introductory CS textbook.
