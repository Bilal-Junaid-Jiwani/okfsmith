# Grace Hopper

Grace Hopper (1906–1992) was a United States Navy rear admiral and one of the
first programmers of the Harvard Mark I computer[^hopper-wiki]. She developed
the A-0 system, one of the first compilers — a program that translates a
human-readable language into machine code — which led directly to the COBOL
business language[^hopper-wiki].

## Why she is in this curriculum

[CS 101](/courses/cs101.md) opens with Hopper's story to answer the first
question every beginner asks: why do programming languages exist? Her answer —
that computers should be programmed in words people understand, not machine
code — is the premise of every modern language.
